# MedScan AI

MedScan AI is a premium, modern, minimal healthcare application designed for Android using Flet.

## Features
- Appointment Booking with SQLite persistence (Encrypted Patient Data)
- AI-powered Health Report Scanner
- Health Risk ML Diagnostics
- Medicine Schedule & Reminders

## Setup Instructions

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/vikash-2006/medscan-ai.git
    cd medscan-ai
    ```

2.  **Install dependencies:**
    ```bash
    pip install flet cryptography pytest
    ```

3.  **Run the application:**
    ```bash
    python3 app/main.py
    ```

4.  **Run tests:**
    ```bash
    pytest tests/
    ```
